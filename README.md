📊 ProjectNeoway

Projeto de análise e gerenciamento de dados utilizando SQL, desenvolvido no MySQL Workbench. O projeto tem como objetivo trabalhar com uma base de dados relacionada às operações da Neoway, realizando consultas, análises e extração de informações relevantes para apoiar a interpretação dos dados.

🎯 Objetivo

Desenvolver habilidades práticas em SQL e banco de dados, utilizando consultas para explorar informações, analisar resultados e responder a diferentes questões relacionadas aos dados disponíveis.

🛠️ Tecnologias utilizadas
MySQL
MySQL Workbench
SQL
📂 Estrutura do projeto

O repositório contém diferentes scripts SQL desenvolvidos durante o projeto:

neoway24.sql — estrutura e dados utilizados no projeto.
consultas.sql — consultas SQL para exploração e análise dos dados.
novasvendas.sql — consultas relacionadas a novas vendas.
perdas1.sql — análise de perdas.
receita.sql — consultas relacionadas à receita.
complemento.sql — consultas e complementos desenvolvidos durante a análise.
🔎 Análises realizadas

Entre as atividades desenvolvidas estão:

Consulta e exploração de dados;
Filtragem e organização de informações;
Análise de vendas;
Análise de perdas;
Análise de receita;
Criação de consultas SQL para obtenção de informações específicas;
Manipulação e relacionamento de dados utilizando SQL.
📚 Aprendizados

Este projeto contribuiu para o desenvolvimento de conhecimentos práticos em:

Criação e execução de consultas SQL;
Manipulação de bases de dados relacionais;
Utilização de filtros e condições;
Organização e interpretação de dados;
Análise de informações utilizando SQL;
Utilização do MySQL Workbench para desenvolvimento e gerenciamento do banco de dados.
🚀 Como executar
Instale o MySQL e o MySQL Workbench.
Clone este repositório.
Abra o MySQL Workbench.
Execute o arquivo neoway24.sql para criar/carregar a base de dados.
Execute os demais arquivos .sql conforme a análise desejada.
